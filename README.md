# +EVO Events Calendar

Shared events-planning calendar for TEVO. Next.js 14 (App Router), Supabase,
Vercel, Tailwind.

- **New here?** Read [`ONBOARDING.md`](ONBOARDING.md) (setup, env vars, how the
  project is run) and [`CLAUDE.md`](CLAUDE.md) (project brief and working rules).
- **Run locally:** `npm install`, add `.env.local` (see ONBOARDING), then `npm run dev`.
- **Checks:** `npx tsc --noEmit` and `npm test`.
- **Database changes:** see [`MIGRATIONS_APPLIED.md`](MIGRATIONS_APPLIED.md).
- **What changed and when:** [`CHANGELOG.md`](CHANGELOG.md).
